# Agilent / Keysight 34937A — relay contract v1

This module is composed through the single 34980A factory/session described in `34980A.md`. It is not a separately opened device. Primary evidence: `research/34937A-user.pdf`, current own-module guide, PDF/printed pages 15 and 20 for topology and commands, plus the 34980A programmer's ROUTe:CLOSe/OPEN command descriptions.

## Mapping and meaning

Each binding declares a mainframe slot 1–8, positive logical switch channel and local relay channel 1–32. Channels 1–28 are Form C (SPDT); channels 29–32 are Form A (SPST). All are latching. There is no analog bus on this module. Never infer an OpenAll action or an initial de-energized state from opening the software session or cycling mainframe power.

The neutral path means common-to-normally-open for Form C, and the single normally-open path for Form A. **Opening a Form C channel connects common to its normally-closed contact; it does not isolate the circuit.** Boolean state is the instrument's commanded relay state, not contact continuity/physical verification. The application must commission wiring and know the NC/NO consequences.

## Exact operations

For derived address `a = 1000*slot + local`:

| Neutral operation | Exact message | Result |
|---|---|---|
| Switch.CloseChannel(logical) | write `:ROUT:CLOS (@a)` | Unit |
| Switch.OpenChannel(logical) | write `:ROUT:OPEN (@a)` | Unit |
| Switch.ChannelIsClosed(logical) | query `:ROUT:CLOS? (@a)` | Boolean |

No list/range or whole-slot command is emitted; only the selected bound path is addressed. No reset, preset, analog bus, OpenAll or implicit safe shutdown is advertised. Query body is exactly `0` or `1`; anything else, including `ON`, signed numbers, CSV or whitespace, is Parse. A write's completion is not a calibrated/contact-continuity guarantee.

Unmapped logical channels fail before IO. IO/parse/cancellation failure quarantines the shared mainframe; all module views then fail without further traffic. Close releases the resource and leaves latching relays unchanged. Owned/borrowed/native/worker behavior follows the parent contract.

## Independent acceptance

Cover each operation on Form C boundaries 1/28 and Form A boundaries 29/32, slot boundaries 1/8, sparse logical mapping, true/false replies and strict token rejection. Cover duplicate/type/local mapping rejection, no OpenAll capability, write/read transport/timeouts, mainframe-wide quarantine, ownership and concurrent module-view serialization. Preserve the physical NC caveat in README/examples and do not call this fail-safe output isolation.
