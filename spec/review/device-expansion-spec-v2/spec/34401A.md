## Admission and composition

Use canonical ID `keysight.34401a`, exact model `34401A` and manufacturer aliases `HP`, `HEWLETT-PACKARD`, `Agilent Technologies`, `Keysight Technologies`. Comparison is case insensitive. Remove the inherited USB VID/PID hint: this model documents GPIB and RS232, not native USB.

The initial factory accepts an explicitly commissioned GPIB SCPI connection using endpoint scheme `scpi`. RS232 hardware exists, but serial host configuration is deferred in this subset. Require exclusive access, known front/rear terminal selection, correct wiring/fuses, SCPI language and a clean response boundary. Persistent HP3478A/Fluke emulation is not admitted. Metadata and opening perform no IO. The connector must enforce finite deadlines and a 256-byte response allocation bound, strip the GPIB LF terminator, preserve the body exactly and reject binary blocks before removing headers.

A range is an expected signal magnitude, not necessarily a nominal instrument range. Accept absent range or any finite positive number at or below the listed maximum. The instrument selects an appropriate range. Reject zero, negative, nonfinite and above-maximum arguments before IO. These software checks do not provide electrical input protection.

Format an explicit range as 12 significant digits: one digit, decimal point, 11 fraction digits, uppercase `E`, exponent sign and at least two exponent digits. Normalize .NET `E11` exponent padding to match Rust. For example, 10 becomes `1.00000000000E+01`. Reuse the previously qualified formatter; do not create a different midpoint-rounding implementation. The wire parameter is this rounded representation.

Each method sends exactly one query. MEAS is an explicit state-changing operation: it selects the requested function, presets AC filter 20 Hz, sample count 1, trigger count 1, immediate trigger, automatic delay, math off, fixed 10 MOhm input resistance and the documented default resolution/autozero. Default resolution is 5.5 digits slow/10 PLC. A deadline must accommodate integration and settling; a short timeout may fail normally. Each result gets its physical unit from its current method, without cached configuration assumptions.

## Exact reply policy

The body is exactly 15 ASCII characters in the documented form `SD.DDDDDDDDESDD`: a leading `+` or `-`, one digit, point, eight fraction digits, uppercase `E`, exponent sign, two exponent digits. Example: `+1.25000000E+00`. Reject spaces, extra fields, control characters, headers, units and binary blocks.

Exact positive `+9.90000000E+37` is the documented overload. Return value 0, the requested physical unit and Overload status. Other finite values with absolute value less than `1e30` are Good. Any other value with absolute value at least `1e30`, including negative `-9.90000000E+37`, is Parse: this is an explicit broad software plausibility policy, not another claimed instrument sentinel. Nonfinite or malformed bodies are Parse. Do not label a huge sentinel Good or apply `abs()` when recognizing overload.

## Lifetime and verification

Serialize the whole query under one SDK lease. Mark uncertainty before host IO. IO, parse or cancellation failure quarantines the session; subsequent operations fail without more traffic. Invalid arguments leave the session usable. No retry, implicit reset or bus clear occurs. Owned resources close exactly once; borrowed resources remain open. Close sends no device commands. Native async is advertised only with a genuine async connector; synchronous connectors use SDK workers. External resynchronization and reopening are required after uncertainty.

Independent acceptance must cover all seven methods, both range forms, argument boundaries, overload, negative/zero readings, every grammar rejection, failures and quarantine, passive registration, ownership and actual pending cancellation/deadlines. Execute the same oracle in Rust/C# sync/native/worker frontends and source/packed Native AOT consumers on Windows/Linux x64, .NET 8/10.
