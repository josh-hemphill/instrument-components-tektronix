# Agilent / HP 53132A — extracted contract v1

This is a proposed manual-derived software subset, not hardware validation. Primary source: `research/53132A-programming.pdf`, shared 53131A/53132A guide 53131-90044. Relevant printed pages: 4-53–54 (PDF 221–222), 4-57–59 (PDF 225–227), 4-63–64 (PDF 231–232), 4-68–69 (PDF 236–237), 4-87 (PDF 255), and 4-41 for ASCII data format.

## Admission and capabilities

Canonical ID `keysight.53132a`; exact model `53132A`; case-insensitive manufacturer aliases `HP`, `HEWLETT-PACKARD`, `Agilent Technologies`, `Keysight Technologies`. The initial factory accepts commissioned addressed GPIB SCPI through endpoint scheme `scpi`. No USB identity or command-capable serial interface is inferred from the documented serial transmit functions.

Require exclusive access, suitable physical input conditioning/carrier, a clean bounded response stream and finite host deadlines. Opening/metadata perform no IO. Host framing removes only LF and rejects binary blocks. Maximum scalar body/allocation is 256 bytes. Physical input limits remain the application's responsibility.

Support existing Counter.SelectChannel, SetGateTime, MeasureFrequency and MeasurePeriod. Channels 1 and 2 only; optional channel 3, ratio, totalize, reset and other timing/voltage functions are deferred. Initial selected channel is 1 and intended gate is 0.100 seconds. Channel/gate setters change software intent without IO. Each measurement reapplies that intent; an invalid setter changes neither prior intent nor session health.

## Gate contract

Accept finite 0.001 through 1000.000 seconds inclusive on an integer-millisecond grid. This is a declared subset of the manual's native short-gate resolution (1–99.99 ms in 10 us increments) and long-gate resolution (100 ms–1000 s in 1 ms increments). Do not borrow a smaller totalize gate minimum from a different function/firmware page.

Find nearest integer `m` in 1 through 1000000 and require `seconds == m / 1000.0` using binary64 division. Do not require `seconds * 1000` to be exactly integral: that multiplication can reject valid fractions. Format the wire gate from integer `m` with exactly three fraction digits: `0.001`, `0.100`, `1000.000`. Off-grid arguments fail before IO.

## Exact fresh measurement

Frequency performs these separate messages, in this order:

1. Write `:CONF:FREQ DEF,DEF,(@<channel>)`.
2. Write `:SENS:FREQ:ARM:STAR:SOUR IMM`.
3. Write `:SENS:FREQ:ARM:STOP:SOUR TIM`.
4. Write `:SENS:FREQ:ARM:STOP:TIM <gate>`.
5. Write `:FORM ASC`.
6. Query `:READ?`.

Period replaces the first command with `:CONF:PER DEF,DEF,(@<channel>)`; all remaining commands are identical. The frequency arm subtree explicitly applies to frequency, ratio and period. CONFIG permits `DEF` substitution anywhere and disables math, statistics and limit testing. It enables auto-trigger at 50% with positive edge on the selected input. Apply time-gate settings after CONFIG because CONFIG selects default/digits arming. READ starts a fresh measurement; FETCh would permit stale data. Force ASCII even if a previous controller selected REAL. Return Hertz for frequency and Second for period.

No setting readback or precision/calibration promise is part of setter completion. Whole-operation traffic is serialized. A missing carrier can block measurement; host deadlines and real native cancellation must remain independent of the device's progress. Device Clear is documented to cancel hold-off, but bus recovery is external: no automatic clear/abort/retry is emitted.

## Scalar parser and failure policy

READ returns ASCII NR3 with 1–15 significant digits. Accept an optional leading sign; one or more integer digits; optional decimal point with at least one following fraction digit; mandatory `E` or `e`; optional exponent sign; one through three exponent digits. Count significant mantissa digits after removing leading zeros, retaining trailing zeros; an all-zero mantissa counts as one. Require at most 15 significant digits. Reject whitespace, headers, units, CSV and blocks. Nonfinite or malformed values are Parse.

The documented numeric `9.91E37` means no valid result/Not a Number: report Device and quarantine. Other finite values must be strictly positive. Zero, negative or underflow-to-zero values are Device. Do not convert the invalid-result sentinel into overload or a huge Good measurement. No arbitrary 225 MHz parser cutoff is invented from an expected-input parameter range.

IO, parse, Device or active-cancellation failure quarantines. Invalid local setters do not. Close is resource release only: owned once, borrowed preserved. Native async requires a genuine supplied connector; otherwise use SDK workers. External resynchronization/reopen is required after uncertainty.
